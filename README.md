# flw

Personal DIY terminal-style CSS library for self-hosted projects (Pi kiosks, intranet panels, irrigation toggles, etc.).

Visual philosophy: [STYLE_GUIDE.md](STYLE_GUIDE.md)  
Agent instructions: [AGENTS.md](AGENTS.md)

**MCU displays (ESP32 / Arduino):** companion package [09-flw-UI-microcontroller-components](../09-flw-UI-microcontroller-components) — TFT preview lab, RGB565 tokens, Public Pixel charset.

## Install

**First-time setup** (downloads SIL OFL fonts into `fonts/`; the glyph subsets are committed, regenerate with `python3 scripts/fetch-glyphs.py`):

```bash
npm run fetch-fonts
npm run build
```

**Copy (simplest)**

```bash
npm run build
cp -r dist/flw.css dist/flw.js dist/fonts /path/to/your/project/
```

**Git dependency** (when this repo is available locally or via git)

```json
{
  "dependencies": {
    "flw": "file:../08-flw-UI-components"
  }
}
```

Then link `node_modules/flw/dist/flw.css`.

## Usage

```html
<link rel="stylesheet" href="flw.css" />
<script src="flw.js"></script>
<script>flw.auto()</script>
```

Fonts (Space Mono 400/700, Noto Emoji, flw Glyphs — DejaVu subsets for `█ ░ ● ─ ⠋ …`) load from `@font-face` inside `flw.css` — works offline on a Pi with no CDN, and glyphs look the same on every device.

Optional JS widgets use `data-flw-*` attributes:

- `data-flw-spinner` — Braille spinner
- `data-flw-marquee` — scrolling overflow text (`.flw-marquee--stepped` + `data-flw-marquee-fps="8"` for a ticker)
- `data-flw-range` — live readout for `.flw-range`, shift + arrows for ×10 steps
- `data-flw-scrub` — drag-to-change number (`.flw-scrub`), shift ×10, click to type
- `data-flw-accordion="single|multi"` — collapsible panes
- `data-flw-tabs` — tab panels
- `data-flw-bar` + `data-flw-bar-value="42"` — glyph progress bar (`data-flw-bar-color="blue"` for identity color)
- `data-flw-shade="65"` — ░ ▒ ▓ intensity behind a value

CSS works without JS. Accordion also works via `<details class="flw-details">`. Tabs require JS.

## Build

```bash
npm run build
```

Outputs `dist/flw.css` and `dist/flw.js`.

## Visual QA

```bash
npm run serve
```

Open http://localhost:5173/overview — catalog of every token, utility, layout, and component. http://localhost:5173/synth shows the `.flw-app` tool shell in use.

`serve` runs `build` first and copies `dist/` into `examples/dist/` so asset paths resolve when the examples folder is the server root. The server is `scripts/serve.js` — plain Node, no dependencies, works offline (`PORT=8080 npm run serve` for another port).

Workflow: change CSS in `src/` → `npm run build` (or re-run `serve`) → refresh overview.

## Structure

```
src/tokens.css          design tokens
src/fonts.css           @font-face (generated by fetch-fonts)
src/glyphs.css          @font-face for flw Glyphs (DejaVu subsets, fetch-glyphs.py)
fonts/                  woff2 files (Space Mono + Noto Emoji, ~600KB)
src/typography.css      prose + emoji tiers
src/base.css            reset + focus
src/utilities.css       helpers
src/layout.css          page/grid/stack
src/components/*.css    UI primitives
js/flw.js               optional behavior
examples/overview.html  debug catalog
examples/synth.html     app shell example (drone-o-mat)
```
